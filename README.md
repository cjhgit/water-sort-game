# 倒水大师 · Water Sort

经典倒水排序益智游戏（Water Sort Puzzle）的单文件网页实现，移动端优先。

**在线游玩**：https://cjhgit.github.io/water-sort-game/

## 玩法

- 点击瓶子拿起，再点击目标瓶倒入；只有顶部颜色相同或空瓶可以倒入
- 把每种颜色归拢到同一个瓶子（4 层同色）即过关
- 卡住了可以「加瓶」（加一个空瓶）或「撤销」

## 特性

- **20 个渐进关卡**：2 色 4 瓶 → 12 色 14 瓶
- **每关保证有解**：逆向打散生成（从完成态做可逆倒水打乱），打散序列的逆即答案；个别极端情况回退到随机发牌 + BFS 可解性验证
- **答案演示**：一键自动播放本关解法，随时可中断接手
- **三星评价**：按步数评分（≤1.5× 最优三星，≤2.2× 两星）
- **科学配色**：12 色调色板经 CIE ΔE 校验，任意两色差 ≥ 34.4，色弱友好
- **移动端适配**：44px 触控目标、安全区适配、响应式网格、禁缩放/回弹
- 纯原生 HTML/CSS/JS，单文件零依赖，无构建步骤

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

或直接双击 `index.html`。

## 技术

- 关卡生成：逆向打散（guaranteed-solvable by construction）
- 求解器：BFS（状态去重 + 剪枝），用于兜底验证与最优步数参考
- 渲染：SVG 瓶身（渐变液体 + 玻璃高光），CSS Grid 自适应布局
- 进度存档：localStorage
